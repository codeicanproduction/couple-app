# Couple App

A mobile application for couples to stay connected and organized.

## Tech Stack

- **Frontend:** Next.js / React Native
- **Backend:** Node.js
- **Database:** TBD

## Getting Started

```bash
npm install
npm run dev
```

## Contributing

- All changes must go through a Pull Request
- Direct pushes to `main` are not allowed
- At least 1 reviewer approval required before merge
